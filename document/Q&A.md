# 데이터 엔지니어 Q&A

> 실무 경험을 기반으로 면접 답변 초안을 정리한 문서

## Hard Skill

### 경험한 분산 처리 경험을 설명해 주세요

- Apache 계열 도구(Spark, Hive, Hadoop, Sqoop, Airflow) 중심으로 경험 있음
- 온프레미스 환경에서 ETL 기반 DW, DM 구축 경험 있음
- PySpark로 트렌드 키워드 랭킹, 상품 정보 추출, 데이터 클렌징 작업 수행함
- Airflow로 배치와 준배치 스케줄링까지 운영함

### 다른 환경 경험은?

- 하이브리드 환경에서도 ETL, ELT 파이프라인 구축 경험 있음
- Athena, S3, Glue, Databricks, Elasticsearch 조합 사용 경험 있음

### 추가로 정리할 질문

- 데이터 모델링과 데이터 아키텍처 설계 경험
- 클라우드 기반 컴퓨팅 플랫폼 활용 경험
- SQL / NoSQL 사용 경험과 장단점
- Java, Scala, Python 사용 경험

## Soft Skill

### 협업 관련 질문

- 다양한 팀과 요구사항을 조율한 경험
- KPI 정의 과정과 데이터 해석 방식

### 운영 관련 질문

- 데이터 품질 문제를 발견하고 해결한 사례
- 장애 대응과 후속 커뮤니케이션 방식

### 조직 협업 질문

- 데이터 기반 의사결정 지원 경험
- 기술 조직과 협업하며 겪은 도전 과제
