# 자연어 처리 개요

> NLP의 큰 흐름과 기본 하위 개념을 빠르게 훑기 위한 요약 문서

## 문서 정보

- 작성일: 2023-07-31
- 참고 자료: [NLP 개요](https://cumulu-s.tistory.com/5)

## 핵심 포인트

- NLP는 사람이 사용하는 언어를 기계가 처리하도록 만드는 분야임
- 전처리, 표현, 이해, 생성 단계로 나눠서 보는 편이 이해하기 쉬움
- NLU와 NLG는 실무에서 자주 분리해서 설명함

## NLP란

- Natural Language Processing의 약자임
- 텍스트나 음성 같은 자연어 데이터를 분석하고 처리하는 기술 영역임
- 검색, 분류, 요약, 번역, 챗봇 같은 문제에 활용됨

## NLU

- Natural Language Understanding의 약자임
- 입력 문장의 의미를 해석하는 영역임
- 의도 분류, 개체명 인식, 감성 분석, 질의 이해가 여기에 포함됨

## NLG

- Natural Language Generation의 약자임
- 기계가 자연어 문장을 생성하는 영역임
- 요약, 번역, 답변 생성, 문서 작성 자동화가 대표 사례임

## 실무 흐름 메모

1. 원천 데이터 수집
2. 텍스트 정제와 전처리
3. 토큰화와 벡터화
4. 모델 학습 또는 추론
5. 결과 평가와 운영 반영
