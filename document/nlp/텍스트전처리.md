# 텍스트 전처리

> NLP 파이프라인에서 가장 먼저 다루는 텍스트 정제 과정을 정리한 문서

## 문서 정보

- 작성일: 2023-07-31

## 핵심 포인트

- 텍스트 전처리는 모델 성능에 직접 영향을 줌
- 언어와 도메인에 따라 전처리 방식이 달라짐
- 토큰화, 정규화, 불용어 처리, 인코딩이 기본 축임

## 전처리 항목

- Data parsing
- Tokenization
- Stemming
- Lemmatization
- Stopword 제거
- Regular Expression 처리
- Padding
- Encoding
- Train / Validation / Test Split

## 자주 하는 작업

### 정규화

- 대소문자 정리
- 특수문자 제거
- 공백 정리

### 토큰화

- 문장 단위 분리
- 단어 단위 분리
- 서브워드 단위 분리

### 형태 정리

- 어간 추출
- 표제어 추출
- 불용어 제거

## 운영 메모

- 한국어는 형태소 분석기 선택이 중요함
- 로그, 리뷰, 검색어처럼 데이터 성격에 따라 전처리 규칙이 크게 달라짐
