# Delta Lake

> 데이터 레이크에 트랜잭션과 스키마 관리 기능을 추가하는 저장 계층 정리

## 핵심 포인트

- Delta Lake는 데이터 레이크 위에 ACID 트랜잭션 기능을 더함
- Delta Table은 Delta Lake 포맷으로 관리되는 테이블임
- `_delta_log`를 통해 스키마, 버전, 변경 이력을 관리함

## Delta Lake란

- 데이터 레이크를 테이블처럼 운영하기 위한 오픈소스 스토리지 계층임
- 기본 적재는 append 중심이지만, update, delete, merge 같은 작업도 지원함
- 데이터 품질과 재현성을 높이는 데 유리함

## Delta Table이란

- Delta Lake 포맷을 사용하는 테이블임
- 실제 데이터 파일과 트랜잭션 로그를 함께 참조함

## Data Lake와 비교

### Data Lake

- 일반적으로 Schema on Read 방식임
- 원시 데이터를 유연하게 저장하는 데 강함

### Delta Lake 특징

- 보통 Schema on Write 방식으로 운영함
- 쓰기 시점 검증과 버전 관리가 가능함
- 트랜잭션 로그 기반으로 최종 스키마를 해석함

## 운영 관점 메모

- 스키마 변경이 잦은 환경에서 추적성이 좋음
- 배치와 스트리밍을 함께 운영할 때 유용함
- 작은 파일 관리와 로그 정리 전략이 필요함
