# LLM - LangChain

> LLM 애플리케이션을 구성할 때 자주 함께 언급되는 개념과 도구를 빠르게 정리한 문서

## 문서 정보

- 작성일: 2024-01-07

## 핵심 포인트

- LLM은 대규모 텍스트 패턴을 학습해 자연어를 이해하고 생성함
- LangChain은 LLM 애플리케이션을 조합형으로 만들기 위한 프레임워크임
- LangSmith, Lilac 같은 보조 도구와 함께 운영·평가 체계를 구성할 수 있음

## LLM이란

- LLM은 Large Language Model의 약자임
- 자연어 처리(NLP) 영역에서 대량 텍스트 데이터를 학습함
- 문장 생성, 요약, 분류, 질의응답 같은 작업에 활용됨

## LangChain이란

- LLM 애플리케이션 개발을 돕는 프레임워크임
- 프롬프트, 체인, 메모리, 도구 호출, 에이전트 구성을 지원함
- Python과 JavaScript 생태계에서 널리 사용됨

## 함께 보는 도구

### LangSmith

- 체인 실행 추적
- 디버깅과 평가
- 운영 관측성 확보

### Lilac

- 데이터셋 구조화
- 샘플 탐색과 필터링
- 모델 출력 분석

## 정리

- LLM 자체는 모델이고, LangChain은 이를 애플리케이션으로 엮는 도구에 가까운 편임
- 실제 운영에서는 프롬프트 설계만이 아니라 평가, 추적, 데이터 품질 관리가 함께 필요함
