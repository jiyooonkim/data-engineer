# 자료구조

> 데이터 접근 방식과 처리 비용을 이해하기 위한 기본 자료구조 메모

## 문서 정보

- 작성일: 2023-08-02

## 핵심 포인트

- 자료구조는 데이터 저장 방식과 탐색 비용을 결정함
- 같은 데이터라도 구조를 어떻게 잡느냐에 따라 성능 차이가 큼
- 해시, 큐, 스택은 실무에서 가장 자주 마주치는 기본 구조임

## 빠르게 보는 정리

| 구조 | 설명 | 대표 특징 |
| --- | --- | --- |
| Hash | 키 기반 조회 구조 | 평균 `O(1)` 조회 |
| Queue | 먼저 들어온 데이터가 먼저 나감 | FIFO |
| Stack | 나중에 들어온 데이터가 먼저 나감 | LIFO |

## 언제 중요해지나

- 대량 데이터 조회 성능을 고민할 때
- 스트리밍 처리 순서를 보장해야 할 때
- 재귀, 파싱, 실행 컨텍스트를 다룰 때
