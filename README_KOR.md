# ⚙️ 검색 사전 및 데이터 엔지니어링 프로젝트

> 검색, NLP, 분석, 플랫폼 운영을 위한 기초 데이터를 구축하는 저장소임

## 개요

좋은 기초 데이터가 좋은 결과를 만듦.

이 저장소는 검색 사전 구축, 학습 데이터 정제, NLP 실험, 데이터 플랫폼 운영 메모를 한곳에서 관리하기 위한 프로젝트임.

## 📌 핵심 스택

- Hadoop
- PySpark
- Python
- Shell
- Hive
- Elasticsearch

## 🧱 버전 메모

- Python `3.9`
- PySpark `3.5.1`
- Hadoop `3.3.4`
- Airflow
- Jenkins

## 🎯 목적 및 방향성

- 데이터 엔지니어링 기반으로 좋은 기초 학습 데이터를 생성하는 목적임
- NLP 기반 가설을 세우고 직접 개발을 주도하는 흐름을 지향함
- 데이터 연관성과 특징을 이해하는 훈련을 축적하는 목적임
- AI/ML 학습을 위한 데이터 준비와 실험 감각을 함께 키우는 목적임
- Hadoop, Python, Spark, Hive 중심으로 안정적인 플랫폼 구축과 운영 방식을 탐색함
- 검색과 추천을 위한 데이터 개발을 주요 축으로 둠
